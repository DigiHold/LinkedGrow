## Overview

xAI provides Grok 4, Grok 4.1 Fast, Grok Code Fast, and Grok 3 models. Grok models are known for their conversational, engaging writing style and trend awareness, making them a solid choice for LinkedIn content.

## Step 1 - Create an xAI account

1. Go to [console.x.ai](https://console.x.ai/team/default/api-keys)
2. Create an account or sign in
3. Verify your email

## Step 2 - Set up billing

1. In the xAI Console, navigate to billing settings
2. Add a payment method (credit or debit card)
3. xAI uses pay-as-you-go billing

## Step 3 - Generate your API key

1. Go to [console.x.ai/team/default/api-keys](https://console.x.ai/team/default/api-keys)
2. Click **Create API Key**
3. Copy the key - it starts with `xai-`

## Step 4 - Configure in LinkedGrow

1. Go to **Settings > AI API** in LinkedGrow
2. Click the **Grok** tab
3. Paste your API key in the key field
4. Select a model from the dropdown
5. Click **Save**

## Available models

| Model | Best for | Cost per post | Monthly estimate (30 posts) |
|---|---|---|---|
| Grok 4 | Highest quality | ~$0.03 | ~$0.90 |
| Grok 4.1 Fast (Recommended) | Best value for quality | ~$0.01 | ~$0.30 |
| Grok Code Fast | Fast generation | ~$0.005 | ~$0.15 |
| Grok 3 | Balanced option | ~$0.03 | ~$0.90 |

**Recommendation:** **Grok 4.1 Fast** offers excellent content quality at a competitive price point. It is fast and produces engaging, natural-sounding LinkedIn posts.

## Key format

Grok API keys start with `xai-` followed by a string of characters.

Track your usage in the xAI Console dashboard. Review your API call history and costs to monitor spending.
